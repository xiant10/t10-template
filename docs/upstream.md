# Upstream items

What this project has learned that the foundation should take back. Each item names our workaround here and the change we'd propose there. A workaround in this repo carries its ID in a comment (`# upstream U3: …`), so `grep -rn 'upstream U3'` finds what to remove once the fix is in a pinned image.

Proposing a fix is a normal change in `~/projects/t10`, never an edit made from here. This repo picks it up only by bumping a pin in `foundation/versions.env`.

Status is one of `open`, `proposed <link>`, `merged <repo>@<sha>` and `done` (the workaround is gone).
